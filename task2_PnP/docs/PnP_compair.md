# 几种PnP解算算法分析

- 为了代码整洁，除了后面使用的IPPE算法，其他均未使用多解筛选
1. IPPE、AP3P、SQPnP、ITERATIVE：效果最好，基本不抖动
2. EPnP：z轴绘画不稳定，不垂直与装甲板平面
3. P3P：抖动最剧烈，无法使用

- 分析：本项目目标——装甲板是平面目标，并且尺寸较小。因此：
1. IPPE这种专为平面设计的可以起到较好并且稳定的效果;
2. SQPnP、ITERATIVE这种针对数值进行最优化的在图像不复杂，特征点明显的情景也比较合适
3. AP3P是数值条件好的4点最小解,但Ke的代数形式数值条件好得多
4. EPnP通过4个虚拟控制点线性求解，不迭代，也不约束平面，容易导致平面退化，导致z轴解算出错
5. P3P虽然也使用最小解，但是只用3点，四解靠第四点挑。并且由于是平面，就把位姿定死,本身没有冗余去平均角点噪声。同时，P3P有最多四个候选解，没有进行筛选也会产生严重抖动
